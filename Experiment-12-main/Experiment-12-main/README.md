# Campusly – Student Management System

## 📌 Project Description

Campusly is a responsive student management web application developed using React and Vite. It provides a simple and user-friendly interface for students to explore information about the application, access registration and login pages, and contact the platform.

The application consists of five main pages: Home, About, Contact, Register, and Login. React Router is used to navigate between these pages without reloading the entire website. A shared header and footer provide a consistent layout throughout the application.

The project focuses on frontend development, component-based architecture, responsive design, form handling, and client-side navigation.

## 🎯 Objectives

- To develop a student management website using React.
- To create multiple pages with smooth navigation.
- To implement login and registration form interfaces.
- To design a responsive layout for desktop and mobile devices.
- To understand React components, routing, and form validation.
- To organize a frontend project using reusable components and CSS.

## 🛠️ Technologies Used

- **React:** Used to build interactive user interfaces using reusable components.
- **JavaScript:** Used to implement application logic and event handling.
- **Vite:** Used as the development server and build tool.
- **React Router:** Used for navigation between application pages.
- **HTML5:** Used to structure the web application.
- **CSS3:** Used for styling, layout, and responsive design.
- **npm:** Used to manage project dependencies.

## ✨ Features

### 1. Home Page
Provides the main entry point to the Campusly application and introduces the website to users.

### 2. About Page
Displays information about the application and its purpose.

### 3. Registration Page
Provides a form with fields for:
- Full name
- Student email
- Optional student ID
- Password

The form uses browser validation to ensure required fields are completed and the password contains at least eight characters.

### 4. Login Page
Provides email and password fields for users to enter their login details. Both fields are required.

### 5. Contact Page
Provides a contact form with fields for name, email, and message. The page also displays a placeholder contact email address.

### 6. Responsive Design
The layout is designed to adapt to desktop and mobile screen sizes.

### 7. Client-Side Navigation
React Router enables navigation between Home, About, Contact, Register, and Login pages.

### 8. Shared Layout
A common header and footer are used across the pages to maintain a consistent appearance.

Install the following before running the project:

## 🧪 Form Validation

The registration, login, and contact forms use HTML browser-level validation.

- Required fields must be filled in.
- Email fields use email-format validation.
- The registration password must contain at least eight characters.

These checks provide basic input validation in the browser. They do not verify user credentials or store submitted information.

## ⚠️ Current Limitations

Campusly is currently a **frontend-only project**.

- The registration form does not save student information.
- The login form does not authenticate users.
- The contact form does not send messages to a server.
- No backend API or database integration is implemented in the documented application.
- The contact email address is a placeholder.

A backend service and appropriate database integration would be required to support persistent student records, secure authentication, and actual message submission.
